🍄 Mushroom Classification Using Various Machine Learning Algorithms
A machine learning project that classifies mushrooms as edible or poisonous using various algorithms. Includes preprocessing, EDA, model training, and performance comparison between Logistic Regression, Decision Tree, Random Forest, KNN, and SVM. 
The project highlights practical ML techniques and showcases results through accuracy scores and confusion matrices.
🚀 Features

Comprehensive EDA with visualizations

Label encoding of categorical mushroom attributes

Training multiple ML models

Hyperparameter tuning

Model evaluation using:

Accuracy

Precision

Recall

F1-score

Confusion Matrix

Comparison of algorithms to determine the best performer

🧰 Tech Stack

Python

Pandas

NumPy

Scikit-learn

Matplotlib & Seaborn

Jupyter Notebook

📊 Dataset

The project uses the UCI Mushroom Dataset, which contains 22 categorical features describing mushroom characteristics like:

Cap shape

Cap surface

Odor

Gill size

Gill color

Habitat

Population

Target variable:

edible (e)

poisonous (p)

🔄 Project Workflow

Load and explore the dataset

Handle missing values

Apply label encoding to all features

Split into train-test sets

Train the following models:

Logistic Regression

Decision Tree

Random Forest

KNN

SVM

Evaluate each model

Compare their performance

Visualize results
